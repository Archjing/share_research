# 个股消息面跟踪分析模板

适用范围：制造业、材料、设备、新能源、电子、医药、军工、消费、资源品、平台型公司等有明确业务分部、上下游关系或行业景气变量的上市公司。

核心思路：

```text
先拆业务
再找客户
再分消息等级
最后判断消息能否传导到收入、利润和预期差
```

## 一、公司业务拆分

研究个股时，不要直接研究“公司整体”，而是先拆成业务板块。

| 业务板块 | 收入占比 | 利润占比 | 下游客户/行业 | 核心驱动因素 | 风险变量 |
|---|---:|---:|---|---|---|
| 业务 A |  |  |  | 需求、订单、价格、产能 | 价格下跌、客户流失 |
| 业务 B |  |  |  | 客户认证、放量、政策 | 竞争加剧、导入不及预期 |
| 业务 C |  |  |  | 行业周期、库存、出口 | 周期下行、库存高企 |

需要回答的问题：

1. 哪个业务贡献收入？
2. 哪个业务贡献利润？
3. 哪个业务决定估值想象空间？
4. 哪个业务最容易受消息刺激？
5. 哪个业务对公司股价边际变化最敏感？

## 二、订单来源分析

| 业务 | 订单/客户来源 | 客户类型 | 客户集中度 | 可跟踪信号 |
|---|---|---|---|---|
| 主业 1 | 下游龙头客户 | B 端大客户 / 政府 / 经销商 / 消费者 | 高 / 中 / 低 | 招标、中标、扩产、出货 |
| 主业 2 | 行业客户群 | 分散客户 / 平台客户 | 高 / 中 / 低 | 价格、库存、行业景气度 |
| 新业务 | 新兴客户 | 新能源、AI、军工、医药等 | 通常不透明 | 认证、试产、批量供货 |

判断原则：

| 客户结构 | 重点跟踪 |
|---|---|
| 客户集中度高 | 大客户订单、招标、中标、交付节奏、客户资本开支 |
| 客户分散 | 行业景气度、产品价格、渠道库存、终端需求 |
| 新业务客户 | 认证节点、试产进展、批量供货、合同金额 |
| 政府或央国企客户 | 招投标、政策预算、项目建设周期、验收回款 |

## 三、消息分级

不是所有消息都值得同等对待。建议将消息按证据强度分为四级。

| 等级 | 消息类型 | 可信度 | 研究价值 | 使用方式 |
|---|---|---:|---|---|
| A 级 | 公司公告、年报、半年报、重大合同、中标公告、客户正式公告 | 高 | 可作为核心判断依据 | 进入主判断 |
| B 级 | 行业数据、产品价格、政策文件、客户扩产、招投标信息 | 中高 | 需要建立传导逻辑 | 作为重要辅助 |
| C 级 | 媒体报道、券商调研、产业链传闻、社交平台消息 | 中低 | 只能作为观察线索 | 等待验证 |
| D 级 | 无来源传闻、概念炒作、模糊利好 | 低 | 不单独作为投资依据 | 只记录不下结论 |

## 四、消息面传导链

研究任何消息时，都套用下面这条链：

```text
消息事件
→ 对应哪个业务？
→ 影响订单、价格、成本、产能还是估值？
→ 能否传导到收入？
→ 能否传导到利润率？
→ 市场是否已经充分预期？
→ 是否需要公司公告或后续数据验证？
```

常见消息的传导方式：

| 消息类型 | 初步影响 | 需要继续验证 |
|---|---|---|
| 下游客户扩产 | 潜在需求增加 | 公司是否是供应商、供应份额是否稳定 |
| 公司中标项目 | 订单确定性增强 | 金额、交付周期、毛利率、回款条件 |
| 产品价格上涨 | 收入和毛利率可能改善 | 涨价是否可持续、成本是否同步上行 |
| 原材料价格下跌 | 毛利率可能改善 | 公司是否能锁定低成本、产品售价是否跟跌 |
| 新客户认证 | 未来放量可能增强 | 是否进入量产、是否有具体订单 |
| 政策利好 | 行业需求可能改善 | 政策是否带来真实订单或财政资金 |
| 产能投产 | 收入上限提高 | 是否有订单消化、产能利用率是否提升 |

## 五、日常跟踪表

| 日期 | 公司 | 业务板块 | 消息来源 | 消息内容 | 证据等级 | 影响方向 | 业绩传导逻辑 | 后续验证点 |
|---|---|---|---|---|---|---|---|---|
|  |  | 主业/新业务 | 公告/新闻/数据 |  | A/B/C/D | 正面/负面/中性 | 订单、价格、成本、产能、估值 | 等公告/等财报/等价格数据 |

示例写法：

| 日期 | 公司 | 业务板块 | 消息内容 | 判断 |
|---|---|---|---|---|
| YYYY-MM-DD | 公司 A | 主业 1 | 下游客户获得大额订单 | 若公司 A 是该客户核心供应商，则存在订单跟随可能 |
| YYYY-MM-DD | 公司 B | 周期品 | 产品价格连续上涨 | 对收入和毛利率偏正面，需要跟踪库存和开工率 |
| YYYY-MM-DD | 公司 C | 新业务 | 获得头部客户认证 | 偏中长期正面，但需等待批量订单和收入确认 |

## 六、行业适配表

| 公司类型 | 重点跟踪 | 关键问题 |
|---|---|---|
| 周期品公司 | 产品价格、库存、开工率、供需格局 | 价格是否见底或上行？库存是否去化？ |
| 制造业公司 | 下游订单、客户扩产、招标中标、产能利用率 | 订单能否转成收入和利润？ |
| 消费品公司 | 渠道库存、终端动销、提价、品牌势能 | 需求是真恢复还是补库存？ |
| 医药公司 | 临床进展、获批、医保、销售放量 | 审批和商业化是否兑现？ |
| 科技硬件公司 | 客户认证、新产品导入、出货量、供应份额 | 是否进入核心供应链？份额是否提升？ |
| 军工公司 | 订单周期、交付节奏、型号放量、合同负债 | 订单能否稳定转化为收入？ |
| 平台型公司 | 用户增长、变现率、监管、费用率 | 增长和利润率能否同时改善？ |
| 资源品公司 | 商品价格、产量、成本、汇率、政策 | 价格弹性是否大于成本压力？ |

## 七、单只股票结论模板

可以用下面格式输出单只股票的消息面判断：

```text
该公司的消息面主线可以分为：

1. 核心业绩主线
主要由【业务 A】驱动，重点跟踪【下游需求/订单/价格】。

2. 利润弹性主线
主要由【产品价格/成本下降/产能利用率】驱动。

3. 估值弹性主线
主要由【新业务/新技术/政策主题】驱动，但需要验证【客户、订单、收入】。

4. 风险变量
重点关注【价格下跌、客户集中、竞争加剧、政策变化、产能过剩】。

结论：
当前最值得跟踪的是【主线 1】和【主线 2】。短期看消息催化，中期看订单和价格，长期看收入、毛利率和现金流兑现。
```

## 八、最终判断原则

每条消息都至少回答六个问题：

1. 这个消息对应哪个业务？
2. 它影响订单、价格、成本、产能、政策还是估值？
3. 它能否传导到收入？
4. 它能否传导到毛利率或净利率？
5. 它是市场已经知道的信息，还是存在预期差？
6. 后续需要什么证据来验证？

一句话总结：

```text
消息面研究不是追热点，而是判断消息能否转化为订单、收入、利润率和预期差。
```
