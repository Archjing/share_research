## 共通数据表现

### 1. 它们普遍有明显市值扩张

73 只股票 2016-2021 年市值增长中位数为 257.68%。这说明这批公司后来进入 AJ80，不只是价格短期炒作，而是经历了较大的市场定价抬升。

这种市值扩张通常来自三类力量：

1. 利润增长：如宁德时代、迈瑞医疗、药明康德、北方华创。
2. 估值扩张：如白酒、创新药、半导体、新能源。
3. 行业地位重估：如万华化学、海螺水泥、山西汾酒、美的集团。

### 2. 高收益伴随高回撤

个股最大回撤中位数为 -52.48%。这意味着这批公司即使事后看是优质标的，过程中也普遍经历过深度回撤。

结论：

```text
高质量成长股 ≠ 低回撤资产
好公司 ≠ 任意价格买入都舒服
消息面跟踪必须配合估值、趋势和仓位控制
```

### 3. 不是年年有效，而是靠关键年份贡献收益

正收益年份占比中位数为 66.67%。多数股票不是每年上涨，而是在 2017、2019、2020、2021 这些产业趋势或流动性有利年份集中释放收益。

这对研究方法的启发是：

```text
要跟踪“主线何时形成”，而不是只静态判断公司好坏。
```

### 4. 成交活跃，具备研究和交易承载力

73 只股票平均成交额中位数约 5.18 亿元/日，中位换手率约 1.11%。这说明它们普遍不是冷门小票，而是有足够资金参与度的产业龙头或高关注度公司。

### 5. 估值中枢偏高

PE 中位数约 41.33，PB 中位数约 4.34。这批股票的共同点不是“便宜”，而是市场愿意为成长性、行业地位和未来空间支付溢价。

## 外部因素

### 1. 供给侧改革和龙头集中

2016-2017 年，周期品、建材、化工、白酒、家电等行业受益于供给侧改革、行业出清和龙头集中。典型公司包括万华化学、海螺水泥、中国巨石、山西汾酒、美的集团、格力电器。

外部变量：

- 去产能
- 环保限产
- 行业集中度提升
- 龙头议价权增强
- 产品价格修复

### 2. 消费升级与核心资产定价

2016-2020 年，白酒、家电、调味品、乳制品等消费龙头出现较强估值扩张。市场从“周期性消费”转向“品牌壁垒 + 稳定现金流 + 提价能力”的定价框架。

外部变量：

- 居民消费升级
- 高端白酒批价上行
- 渠道库存改善
- 外资流入核心资产
- 低利率环境下稳定现金流资产重估

### 3. 新能源产业链爆发

2019-2021 年，新能源车、光伏、储能、电力设备成为最强产业主线之一。宁德时代、阳光电源、思源电气、帝尔激光等公司收益明显。

外部变量：

- 新能源车渗透率提升
- 欧洲和中国新能源政策推动
- 光伏装机增长
- 储能需求启动
- 电网投资和新能源并网需求

### 4. 医药创新和医疗器械国产替代

2017-2021 年，CXO、创新药、医疗器械、眼科等方向获得市场重估。药明康德、昭衍新药、迈瑞医疗、兴齐眼药等成为高收益样本。

外部变量：

- 创新药投融资景气
- 一致性评价和医保控费推动行业分化
- 医疗器械国产替代
- CXO 全球订单转移
- 专科医疗和消费医疗扩容

### 5. 半导体国产替代和科技自主

2019-2021 年，中美科技摩擦强化了半导体国产替代逻辑。北方华创、中芯国际、寒武纪等代表的硬科技资产获得高关注。

外部变量：

- 中美贸易摩擦
- 国产替代政策
- 晶圆厂扩产
- 半导体设备、材料、设计国产化
- 科创板推出带来的估值体系变化

### 6. 流动性周期和风险偏好切换

2018 年是明显压力测试年份，73 只等权群体下跌 15.31%，但 2019-2020 年快速修复。说明这批股票对流动性和风险偏好非常敏感。

外部变量：

- 去杠杆
- 贸易摩擦
- 利率环境
- 北向资金流入
- 公募基金抱团核心资产
- 疫情后的全球宽松

## 失败或落后样本的共同点

表现靠后的公司主要集中在几类：

1. 传统资源和油气：如中国石油、西部黄金。
2. 军工主题但业绩兑现慢：如中国动力、中国卫星、光启技术。
3. 平台或传媒类商业模式承压：如分众传媒、三六零、世纪华通。
4. 2020 后上市且高估值消化：如寒武纪、中芯国际在 2020-2021 阶段承压。

共同问题：

- 业绩兑现慢
- 估值提前透支
- 行业景气度不连续
- 主题强但订单或利润传导弱
- 大盘风格不匹配

## 对消息面研究模板的启发

这批股票在 2016-2021 年的群像说明，值得长期跟踪的股票通常具备以下特征：

| 特征 | 对应跟踪方法 |
|---|---|
| 行业空间变大 | 跟踪政策、渗透率、下游资本开支 |
| 龙头份额提升 | 跟踪客户结构、价格权、行业集中度 |
| 利润率改善 | 跟踪产品价格、成本、产能利用率 |
| 估值体系变化 | 跟踪市场风格、资金偏好、产业叙事 |
| 订单能验证 | 跟踪公告、招标、中标、合同负债 |
| 流动性足够 | 跟踪成交额、换手率、机构持仓 |

最重要的结论：

```text
消息面不是越多越好，而是要寻找能改变行业空间、公司份额、利润率和估值框架的消息。
```

## 可用于后续筛选的规则

如果要从历史画像反推 AJ80 的选股方法，可以考虑以下硬条件：

1. 所属行业处在政策、技术或价格周期的上行段。
2. 公司是行业龙头或具备清晰份额提升逻辑。
3. 日均成交额足够高，能承载资金交易。
4. 过去几年至少出现过利润或估值重估。
5. 最大回撤较大时，基本面主线没有被破坏。
6. 消息能落到订单、价格、产能、客户认证、产品放量或政策兑现。
