# 适合本项目的 skills

记录时间：2026-06-25_23-55-57_CST

以下为原文记录：

---

我在线搜了一圈，适合这个项目的 skill 大致分三类。我的建议是：**优先装 Tushare 专项 skill + Deep Research 类 skill，金融通用 skill 可以先观望**。

**最适合**
1. **Tushare / Tushare Finance skill**
   - 用途：A 股行情、财务、指数、资金流、宏观等在线数据查询。
   - 和本项目高度匹配，因为你已经配置了 `TUSHARE_TOKEN` 和 Tushare 在线源。
   - 我搜到的候选包括 [Tushare marketplace 条目](https://awesomeskill.ai/skill/waditu-tushare-skills-tushare)、[Tushare Finance Skill](https://explainx.ai/skills/stanleychanh/tushare-finance-skill-for-claude-code/tushare-finance)、[Tushare A-Share Stock Skill](https://mcpmarket.com/tools/skills/tushare-a-share-stock-analysis)。
   - 推荐用途：实时补查个股、指数成分、财务指标、行情字段，而不是替代本地历史库。

2. **Deep Research skill**
   - 用途：结构化深度研究，先列提纲，再逐层调查，适合行业、个股、政策、产业链专题。
   - 候选：[Deep-Research-skills](https://github.com/Weizhena/Deep-Research-skills)。
   - 推荐用途：做“某行业主线研究”“某公司业务关系图谱”“政策影响链条”这类长报告。

3. **Financial Research Analyst skill**
   - 用途：股票、行业、主题研究，强调结构化分析和审计轨迹。
   - 候选：[daisy-financial-research](https://github.com/Agents365-ai/daisy-financial-research)、[Bigdata financial research analyst](https://github.com/Bigdata-com/skills-financial-research-analyst)。
   - 注意：Bigdata 那个依赖 Bigdata.com MCP，未必适合你现在的本地数据体系。

**可以参考但不急着装**
4. **finance-skills / awesome finance skills**
   - 候选：[finance-skills](https://skillsllm.com/skill/finance-skills)、[awesome-finance-skills](https://github.com/rkiding/awesome-finance-skills)。
   - 更偏通用金融分析、估值、建模，可能和 A 股数据源适配不如 Tushare 直接。

5. **stock-mcp**
   - 候选：[stock-mcp](https://skillsllm.com/skill/stock-mcp)。
   - 如果你想把 A 股/美股/加密行情做成 MCP 数据服务，可以研究；但你现在已经有本地 SQLite 三市场历史库，短期没必要增加一套 MCP 复杂度。

**我对本项目的推荐组合**
- 必装/优先集成：`Tushare skill`
- 可装：`Deep Research skill`
- 项目内已做：`.agents/SKILL.md`，负责把本项目的目录、数据源、口径、报告规范固化下来
- 暂不建议：Bigdata 类依赖外部商业 MCP 的 skill，除非你明确要接它的数据源

OpenAI 官方也说明 skill 的定位就是把任务说明、资源和脚本打包成可复用能力，适合你这种长期项目工作流沉淀；参考 [OpenAI Agent Skills 文档](https://developers.openai.com/codex/skills) 和 [openai/skills 目录](https://github.com/openai/skills)。
