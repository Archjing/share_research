# 中国股市调查研究项目

这是一个长期反复进行的中国股市调查研究项目。

项目目标是通过个股、行业、指数样本、消息面、基本面和历史数据回看，逐步沉淀可复用的 A 股研究方法论、候选池筛选框架和交易启发。

本项目不是投资建议仓库，也不是一次性回测仓库。这里保存的是持续研究过程中的材料、报告、数据口径、阶段性结论和会话记忆。

## 研究目标

本项目重点回答几类问题：

1. 一只股票的消息面如何影响市场预期、收入、利润率和估值框架？
2. 不同行业应该跟踪哪些关键变量？
3. 历史上跑出来的优秀股票，在早期通常具备哪些共同画像？
4. 候选股池如何从产业逻辑、财务表现、市场表现和数据质量中逐步筛选？
5. 哪些结论只是成功样本归纳，哪些可以进一步发展成可验证的研究流程？

## 核心方法论

当前项目的基础研究框架是：

```text
先拆业务
再找客户
再分消息等级
再判断业绩传导
最后用数据验证与风险约束
```

研究一条消息时，优先判断：

1. 这条消息对应哪个业务板块？
2. 它影响订单、价格、成本、产能、政策还是估值？
3. 它能否传导到收入？
4. 它能否传导到利润率？
5. 市场是否已经充分预期？
6. 后续需要用公告、财报、行业数据还是价格数据验证？

## 数据口径原则

量化或历史回看结论必须先说明口径。

重点记录：

- 数据来源和日期。
- 前复权、后复权或未复权。
- 等权、市值加权或指数权重。
- 固定成分、动态成分或可交易样本。
- 绝对收益、相对收益或净值比值超额收益。
- 是否存在幸存者偏差。

历史经验显示，部分早期前复权价格可能出现穿零或异常收益。长期收益分析优先使用更稳定的口径，例如：

```text
未复权收盘价 × 复权因子
```

## 常用工作流

### 开始一项研究

1. 明确研究对象：个股、行业、指数样本、候选池或消息事件。
2. 查阅 `TRACK.md`，确认是否已有相关研究。
3. 查阅 `reports/`、`notes/`、`MEMORY/`，避免重复劳动。
4. 明确数据来源、时间区间和计算口径。
5. 输出报告到 `reports/`，输出总结到 `notes/`。

### 归档会话

使用 `PROMPTS.md` 中的短指令：

```text
归档会话记录
```

归档时从上一次归档结束点开始增量保存，不重复写入已经归档过的消息。

### 收工

使用 `PROMPTS.md` 中的短指令：

```text
收工
```

收工时更新 `TRACK.md`，把当日新增或更新的报告、总结和会话归档纳入长期轨迹。

## 风险声明

本项目内容只用于研究、复盘和方法论沉淀，不构成任何投资建议。

历史收益、回测结果、候选池表现和个股画像都不代表未来收益。涉及当前市场、公司公告、财务数据、政策和价格信息时，应重新核验最新来源。
