|---|---:|---:|
| AJ80 73只等权群体 | 394.91% | 32.66% |
| 沪深300 | 53.74% | 7.90% |
| 中证1000 | -6.41% | -1.16% |
| 上证指数 | 21.62% | 3.52% |

意思是：

- AJ80 自己涨了 394.91%
- 沪深300 自己涨了 53.74%
- 中证1000 自己跌了 6.41%

如果要算相对超额收益，粗略看：

- AJ80 相对沪深300累计超额约：`394.91% - 53.74% = 341.17%`
- AJ80 相对中证1000累计超额约：`394.91% - (-6.41%) = 401.32%`

但严格的超额收益最好用净值比值算，例如：

```text
AJ80净值 / 沪深300净值 - 1
```

这样更准确。

## USER

这个数据与刚才计算的等效年化收益率是怎么计算的

## ASSISTANT

这里的“CAGR / 等效年化收益率”是把整个区间的累计收益，折算成每年复利增长率。

公式是：

```text
CAGR = (期末净值 / 期初净值) ^ (1 / 年数) - 1
```

也可以写成：

```text
CAGR = (1 + 累计收益率) ^ (1 / 年数) - 1
```

比如 AJ80 73只等权群体：

```text
累计收益 = 394.91%
期末净值 = 1 + 394.91% = 4.9491
区间 = 2016-05-04 到 2021-12-31，大约 5.66 年

CAGR = 4.9491 ^ (1 / 5.66) - 1
     ≈ 32.66%
```

含义是：

> 如果这 5.66 年每年都以固定复利增长，那么每年大约增长 32.66%，最终会从 1 变成约 4.95。

它不是每年收益率的简单平均。比如年度收益是：

```text
2016: 18.17%
2017: 45.85%
2018: -15.31%
2019: 59.75%
2020: 67.61%
2021: 26.41%
```

不能直接把这些数字相加再除以 6。因为投资收益是复利关系，要用：

```text
(1+2016收益) × (1+2017收益) × ... × (1+2021收益) - 1
```

再折算成年化。

更准确地说：

但它 **不是** 严格意义上的：

> 2021 年一次性买入全部 80 只，然后持有到 2026-06-25。

原因有三个：

1. **部分股票 2021 年还没上市**  
   比如百利天恒、联影医疗、联特科技、中国海油、腾远钴业等，2021 年无法买入。

2. **我们用的是“可交易样本等权”口径**  
   每天只对当天有有效收益的成分股等权。也就是说，早期没有价格的股票不会参与。

3. **日期是 2026-06-24，不是 6月25日**  
   本地历史库最新日线到 `2026-06-24`。

所以最严谨的翻译是：

> 这是一个“用 2026 年选出的 AJ80 股票池，回看 2021-2026 表现”的等权模拟结果。它近似表示：如果你从 2021 年开始持有这些当时已经上市的 AJ80 成分股，并在新成分上市后纳入，那么到 2026-06-24 的历史收益表现。

如果要模拟你说的“2021 年一次性建仓后完全不动”，应该只用 **2021 年初已经上市的那批股票** 单独算一版。

这几番分析，我们能得出什么规律性知识？有什么启发？获得了什么经验？

## ASSISTANT

能得到的核心规律是：

**真正有操作价值的消息，不是“公司有利好”，而是它能不能改变收入、利润率、估值框架或市场预期差。**

这几轮分析给出的经验可以归纳成几条。

**一、好股票往往不是孤立变好，而是踩中了时代主线**

2016-2021 这批后来进入 AJ80 的股票，强势来源主要不是单家公司新闻，而是几个大外部变量：

- 供给侧改革：周期品、建材、化工龙头重估。
- 龙头集中：白酒、家电、调味品、工程机械等强者更强。
- 新能源爆发：电池、光伏、电力设备、储能成为主线。
- 医药创新：CXO、创新药、医疗器械获得估值重估。
- 半导体国产替代：设备、设计、制造、材料被重新定价。
- 流动性宽松：2019-2020 成长股估值扩张。

启发是：**个股研究不能只盯公司公告，要先判断它处在哪条产业主线里。**

**二、优秀股票的共同特征是“高弹性”，不是“低风险”**

73 只股票 2016-2021 的中位 CAGR 是 `23.57%`，但最大回撤中位数是 `-52.48%`。

这说明：

- 好公司也会腰斩。
- 高收益通常伴随高波动。
- 只看长期收益，会低估持有过程的心理和仓位压力。
- 消息面跟踪必须结合估值、趋势和回撤控制。

经验是：**“值得研究”不等于“任何价格都值得买”。**

**三、强势股通常经历了“业绩增长 + 估值重估”双击**

这批股票普遍有几个数据共性：

- 市值明显扩张，中位市值增长约 `257.68%`。
- PE/PB 中枢偏高，说明市场愿意为未来空间付溢价。
- 成交额较高，说明资金关注度足够。
- 多数不是年年上涨，而是在关键年份集中释放收益。

启发是：真正的大机会往往来自：

```text
行业空间变大
+ 龙头份额提升
+ 利润率改善
+ 市场愿意提高估值
```

**四、行业类型决定消息面跟踪变量**

不同类型公司不能用同一套消息标准。

| 类型 | 最该盯的变量 |
|---|---|
| 周期品 | 产品价格、库存、开工率、供给收缩 |
| 制造业 | 订单、招标、客户扩产、产能利用率 |
| 消费品 | 批价、渠道库存、终端动销、提价能力 |
| 医药 | 临床、获批、医保、销售放量 |
| 科技硬件 | 客户认证、新品导入、出货量、供应份额 |
| 军工 | 型号、订单、交付、合同负债 |
| 平台型 | 用户、变现率、费用率、监管 |
| 资源品 | 商品价格、产量、成本、分红 |

经验是：**消息面分析要按行业变量建模，不能用“利好/利空”这种粗粒度判断。**

**五、回测结论必须警惕幸存者偏差**

AJ80 历史收益很好，但它是用 2026 年选出的股票回看过去。

所以它不能证明：

> 2016 或 2021 年一定能提前选出这些股票。

它真正有价值的是帮助我们反推：

> 后来跑出来的股票，在早期通常具备哪些共同画像？

这是一种“成功样本归纳”，不是严格策略验证。

**六、数据口径非常重要**

这次分析里有一个很重要的经验：本地库早期 `qfq` 价格出现穿零，导致收益异常。后来改成：

```text
未复权收盘价 × 复权因子
```

才得到稳定结果。

经验是：量化分析里，结论之前必须先确认数据口径。尤其是：

- 前复权/后复权/未复权
- 等权/市值加权
- 固定成分/动态成分
- 可交易样本/完整样本
- 绝对收益/相对收益

这些口径不同，结论会完全不同。

**最终启发**

我们现在得到的方法论可以浓缩成一句话：

**先用产业逻辑找到可能改变公司命运的主线，再用数据验证这些公司是否真的出现了市值扩张、收益弹性、资金关注和业绩传导；最后用回撤和估值控制交易风险。**

下一步最好把这套经验固化成一个“个股研究评分表”：产业主线、公司地位、消息传导、估值位置、资金强度、历史回撤、数据质量，每项打分，形成可复用的研究流程。
